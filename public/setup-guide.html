Complete the free connections

The website combines satellite imagery, searchable infrastructure and a shared aircraft feed. A configured MapTiler browser key opens HD satellite by default; otherwise the regional map is used. Live boats require your AISStream account and one shared collector. Keep all provider accounts on their Free plans.

Zero charges and unlimited availability are different promises.

Use free-only accounts with provider-enforced stops. When free capacity runs out, a layer must pause, become stale or fall back to the regional map. Alerts alone do not stop charges on paid accounts.

Get detailed satellite imagery

  1. Open MapTiler pricing and create a Free account for your non-commercial project.
  2. Leave billing details unset. Keep the account on Free; Flex includes automatic usage charges.
  3. Create a browser key and restrict its allowed origins to the exact website domain. Browser map keys are visible to visitors; domain restrictions protect their use.
  4. Add it to the website runtime as MAPTILER_BROWSER_KEY. It is intentionally a browser key, unlike the private AIS key.
  5. Open the map and select HD satellite. Check the actual local image detail: coverage and acquisition dates vary.

MapTiler currently states 5,000 map sessions or 100,000 API requests per month on Free. This Leaflet implementation uses tile API requests; panning and zooming consume requests. Free service pauses when its allowance is exhausted. The no-key regional fallback is 10m Sentinel imagery with road/place overlays, subject to fair use.

Connect rescue boats once for everyone

  1. Open the private Cloudflare Free connection screen while signed in as the website owner.
  2. Create a scoped Cloudflare deployment token. The screen includes the exact permissions and links.
  3. Enter your Cloudflare account ID, deployment token and AISStream key. Confirm Workers Free, then connect. If a collector already exists, enter your temporary Cloudflare token and choose Update shared collector. Leave the AIS key blank to retain it.
  4. The website checks account subscriptions before deployment. Paid, unrecognised or unreadable subscriptions block the connection. The Cloudflare token is used in memory and is not saved. The AIS key is stored as an encrypted Cloudflare Worker secret.
  5. Use Check status to confirm the collector is running. Fresh watchlisted AIS positions appear as received; a running connection does not establish complete vessel coverage.

One SQLite Durable Object uses up to three filtered AISStream subscriptions for 497 verified vessel identifiers, decodes binary AIS frames and polls the aircraft feed. The website’s atomic request lease keeps aircraft calls within a fixed free budget. Every viewer reads shared website data. Your PC does not need to stay on.

Keep Workers Free selected. Its shared allowances can pause collection before charges occur. This setup does not add payment details, upgrade plans or use a paid fallback. Advanced manual source remains available in the collector package; run only one collector.

How aircraft updates stay within free limits

The current review uses the openly licensed adsb.lol feed, targeting one shared refresh about every three minutes. The optional adsb.fi personal feed targets 30 seconds, but rejected this hosted server during validation and is not selected. Public display of that personal feed also requires confirmation of its terms.

A database lease coordinates every visitor and edge location. Refresh buttons cannot force additional provider polls. Provider 429 responses respect Retry-After; authentication/client errors pause collection. An unavailable budget database stops upstream collection. The private personal adsb.fi option has personal/non-commercial terms; confirm public-display permission before using it for a public site. The default adsb.lol feed has an explicit ODbL data licence.

An approved free adsb.lol key can be added as ADSB_LOL_FREE_KEY. Do not use a paid key while expecting a guaranteed zero API bill. The optional personal feed is selected with ADSB_PROVIDER=adsbfi; the default is adsblol.

Public hosting without automatic overages

This first version remains a private ChatGPT Site for your review. Its publication does not establish an unlimited free public-hosting guarantee. For a public deployment, use a verified free-only hosting account. Cloudflare Pages static assets currently have free, unlimited requests; Workers Free dynamic requests have a shared 100,000/day limit and stop when exceeded. Pages Functions and additional backend products have their own shared allowances. Keep paid usage and automatic upgrades disabled.

More users still consume frontend, tile and backend capacity, even when upstream feeds are shared. A hosted hobby site can be zero-bill with hard stops, but cannot promise service to an unlimited number of people. Account plans and provider terms can change; recheck them before public launch.

Free aircraft key

If the keyless aircraft feed is rate limited, open the private aircraft connection screen. Get an anonymous key from adsb.lol My keys, complete its puzzle and paste the key privately. The anonymous allowance is 500/day; this website caps usage at 480/day. Approved free adhoc keys use a 900/day website cap against the provider’s 1,000/day allowance. Keys are encrypted in server storage and are released only to the authenticated backend worker. Map viewers receive positions, never the key.

Selected aircraft flight tracks

Select an aircraft to display its recorded route. Tracks use the same shared feed, so recording adds no aircraft API calls. A received ground position followed by an airborne report marks the observed departure area. An explicit ground report ends the flight; a landing within 1.5km of the departure is labelled a return to that area, not proof of an operator’s home base.

Routes retain at most 48 hours and the latest three flights, up to 1,000 points per flight. A hard 8,000-record-update daily budget bounds recording writes. Flights first seen airborne have partial tracks. Long reception gaps and implausible jumps are left open. After the shared worker upgrade, capture continues when the map is closed, subject to reception and the free request and recording budgets. Earlier take-off tracks cannot be reconstructed from the current-position API.

Coverage and accuracy

Only received aircraft and AIS positions are plotted. Missing reception does not mean a service is inactive. A station location is never substituted for an unseen aircraft or boat. Positions older than three minutes are shown as last known. Aircraft positions leave the map after fifteen minutes. Boats keep their last received coordinates indefinitely, with their original report times. Vessels never received are listed without invented coordinates. Static facility data is a documented reference, with source links and precision notes; it is still incomplete. General helipads do not imply an ambulance or police operator.
